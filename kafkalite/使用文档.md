# KafkaLite 使用文档

轻量级 Kafka 桌面客户端（Windows）。版本：`0.1.0`

## 1. 获取与启动

### 便携版（推荐）

打包产物路径：

```text
kafkalite/release/KafkaLite.exe
```

双击即可运行。首次运行需本机已安装 **Microsoft Edge WebView2 Runtime**（Windows 10/11 通常已自带）。

若提示缺少 WebView2，可安装：

- [WebView2 Runtime 官方下载](https://developer.microsoft.com/microsoft-edge/webview2/)

### 开发模式启动

```powershell
cd kafkalite
pnpm install
pnpm tauri dev
```

### 重新打包

```powershell
cd kafkalite
pnpm tauri build
```

成功后可执行文件一般在：

```text
kafkalite/src-tauri/target/release/kafkalite.exe
```

也可使用本目录下已复制的：

```text
kafkalite/release/KafkaLite.exe
```

## 2. 界面说明

左侧导航：

| 菜单 | 作用 |
|------|------|
| 连接 | 保存集群、测试连通、激活/断开 |
| Topic | 浏览/创建/删除 Topic，查看分区详情 |
| 消息 | 按条件拉取消息、筛选、导出、发送 Tombstone |

顶部或页面右上角会显示当前连接状态，例如：`已连接 · tail`。

---

## 3. 连接集群

1. 打开 **连接** 页，点击 **新建连接**。
2. 填写：
   - **名称**：自定义，如 `tail`
   - **Bootstrap Servers**：如 `100.72.24.114:19093`
   - **安全协议**：
     - 公司内网明文集群（配置里无 SSL/SASL）→ 选 **PLAINTEXT**
     - 云上常见 → **SASL_SSL**（再填用户名密码）
   - **超时**：默认 `10000` ms 即可
3. 可先点 **测试连接**，成功后再 **保存**。
4. 在列表中点击 **连接** 激活集群。

### 常见连接错误

| 错误 | 可能原因 | 处理 |
|------|----------|------|
| `BrokerTransportFailure` | 网络不通 / 协议不对 | 确认 VPN/内网；核对端口与安全协议 |
| 认证失败 | 用户名密码或 SASL 机制错误 | 按运维文档核对 |
| Topic 列表为空 | 未激活连接或无权限 | 先点「连接」，再刷新 Topic |

> 说明：当前 Windows 默认构建未开启 `ssl-vendored`。公司内网 **PLAINTEXT** 可正常使用；若必须走 SSL/SASL，需按 `README.md` 安装 Perl 后开启 SSL 特性再重新打包。

## 4. Topic 管理

前提：已成功 **连接** 集群。

### 浏览 Topic

- 左侧列表支持搜索、隐藏内部 Topic（`__` 开头）。
- 左右面板各自滚动，互不影响。
- 点击 **详情** 查看分区、Leader、副本、ISR、起始/末尾 Offset。
- 点击 **消息** 跳转到消息查询页并选中该 Topic。

### 新建 Topic

1. 点击 **新建 Topic**
2. 填写名称、分区数、副本因子等
3. 创建

### 删除 Topic

1. 点击某 Topic 的 **删除**
2. 再次输入完整 Topic 名称确认
3. 确认删除（危险操作，请谨慎）

### 删除 Offset 之前的消息

Kafka **不能**像数据库一样随机删某一条中间消息。本功能执行的是：

> 将某分区的日志起始 Offset 推进到目标 Offset，删除该 Offset **之前**的记录。

操作步骤：

1. 打开 Topic 详情
2. 选择分区、填写 `Before Offset`
3. 按提示输入确认文本（须完全一致），格式类似：
   ```text
   集群名/Topic名/分区:目标Offset
   ```
   例：`tail/AMG2_MESSAGE_ARCHIVE_DLQ/0:100`
4. 点击红色按钮执行

## 5. 消息查询

前提：已连接集群，并选择 Topic。

### 查询参数

| 参数 | 说明 |
|------|------|
| Topic | 要查询的主题 |
| 分区 | 全部 / 单个分区 |
| 起点 | **最早（从头读）** / **最新（只读新消息）** / 指定 Offset / 指定时间戳 |
| 条数 | 50 / 100 / 500 / 1000 / 5000 / 10000 |

### 操作按钮

- **开始查询**：开始拉取
- **停止**：中断当前查询
- **导出 JSONL**：导出当前筛选结果
- **清空**：清空列表

### 列表与排序

表头列：

| 分区 | Offset | Key | Value | 时间 |

- 点击 **时间** 按钮可在 **降序 / 升序** 间切换
- 点击某行可在右侧查看详情（原文 / JSON）
- 支持本地筛选 Key / Value / Header

### 结束原因说明

| 显示文案 | 含义 |
|----------|------|
| 已读完或超时无新消息 | 一段时间没有更多消息（idle） |
| 已达到条数上限 | 达到你设置的条数 |
| 用户已停止 | 手动点了停止 |

### 发送 Tombstone（可选）

右上角 **发送 Tombstone**：

- 含义：发送一条「相同 Key、Value 为空」的消息
- 用途：仅对 **compact（压缩）** 策略 Topic 做按 Key 的逻辑删除
- 普通 `delete` 策略 Topic一般用不到

## 6. 推荐使用流程

1. **连接** → 新建/选择配置 → 测试 → 连接  
2. **Topic** → 搜索/刷新 → 看详情  
3. **消息** → 选 Topic → 起点选「最早」或「最新」→ 开始查询  
4. 需要清理历史数据时，在 Topic 详情使用「删除 Offset 之前的消息」

---

## 7. 本地数据说明

- 连接配置保存在本机应用数据目录（SQLite）
- 密码不会明文写进配置库（进程内凭据引用）
- 高风险操作（创建/删除 Topic、DeleteRecords、Tombstone）会写审计记录

---

## 8. 注意事项

1. 大 Topic 请控制条数，避免一次拉取过多导致卡顿。  
2. 删除 Topic / 删除 Offset 之前消息属于危险操作，务必二次确认。  
3. 「最新（只读新消息）」从当前末尾开始，主要用于观察新写入；查历史请用「最早」或指定 Offset。  
4. 公司内网地址（如 `100.x.x.x`）通常需要 VPN 或办公网环境。
